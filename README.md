# Fresh Basket Mobile App

Fresh Basket არის Expo და React Native-ზე შექმნილი მობილური სავაჭრო აპლიკაცია.

## ფუნქციები

- მომხმარებლის რეგისტრაცია
- ავტორიზაცია Fake Store API-ის გამოყენებით
- Yup ვალიდაცია
- react-hook-form ფორმები
- Remember Me ფუნქცია AsyncStorage-ით
- პროდუქტების ჩამონათვალი
- პროდუქტის დეტალების გვერდი
- კალათაში პროდუქტის დამატება
- რაოდენობის გაზრდა და შემცირება
- პროდუქტის წაშლა
- კალათის სრულად გასუფთავება
- საერთო რაოდენობისა და ფასის დათვლა
- პროფილის გვერდი
- პროფილის სურათის არჩევა Expo ImagePicker-ით
- Permissions-ის გამოყენება
- მუქი და ნათელი რეჟიმი
- ორიგინალური Fresh Basket დიზაინი

## გამოყენებული ტექნოლოგიები

- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage
- React Hook Form
- Yup
- Expo Image Picker
- Fake Store API
